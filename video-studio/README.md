# SignalLab OpenFilm editing project

Open with `npx -y openfilm@latest open video-studio` from the repository root. Each actual browser take has its own editable shot on the timeline. The original source recordings are retained unchanged. The approved narration is an audio stream copy from v3; its VTT uses approximate sentence-line timing. Focus movements, reading pauses and chapter labels are editorial. Fresh-case/recall source takes use a local demonstration copy of the same app. No learning-study results are claimed.
