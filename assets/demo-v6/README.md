# Real browser recording sources

Silent Chrome screencast takes recorded while interacting with the working SignalLab application. Navigation, mouse clicks, a threshold drag, keyboard input, scrolling, and resulting UI changes are real. No screen content is fabricated. Chrome emits frames when the page changes; unchanged frames are held between updates.

The edited demonstration adds reading pauses, short captions, smooth crop-and-zoom moves and click-emphasis rings. It is edited application footage, not an uninterrupted session or a human-subject learning study. The fresh-case and recall takes use the same application served locally with separate demonstration progress.

Source capture size: 2294 × 1082. The main edit is 1920 × 1080, with the full viewport displayed edge to edge above captions before each detail zoom. `scripts/build-demo-v6.py` builds from these clips and the unchanged v3 narration.
